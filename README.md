# PolygonTrainMod

PolygonTrainMod is a NeoForge 1.21.1 mod for building polygon-based railway systems in Minecraft.

## Development

1. Install IntelliJ IDEA or another Java IDE.
2. Open this repository.
3. Use a Java 21 SDK.
4. Run the Gradle tasks from the IDE or terminal.

## Current Focus

- Rail placement and rendering
- Train spawning and rail following
- Vehicle model packs
- Cab controls and animation hooks

Small pull requests, assets, and bug reports are welcome.
